# Caderno Digital — Direito do Trabalho II

Caderno digital da disciplina **Direito do Trabalho II**, 8º período, FND/UFRJ, semestre 2026.2.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O projeto foi estruturado em React + TypeScript + Vite e preparado para publicação no Vercel.

### Identidade

- Disciplina: Direito do Trabalho II
- Professor: Prof.º Ivan Simões

O layout toma como referência o caderno digital de Marxismo e Direito, com a paleta visual adaptada ao caderno-base de Direito do Trabalho II.
